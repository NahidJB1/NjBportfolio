The Project & Commercial Scope

Percentage is an active clothing brand operating under Big Dreamers SDN BHD. As a paid contract project, I was commissioned to architect, design, and develop the entire full-stack digital retail ecosystem. The primary business objective was to deliver a high-converting, blazing-fast e-commerce application capable of managing high concurrent traffic, dynamic catalogs, and secure customer profiles.

From mapping user journeys to engineering database layouts and configuring web deployment architecture, I managed the entire lifecycle solo. The platform remains actively maintained and optimized to preserve performance margins under production retail loads.

Technical Execution & Core Components

High-Performance Storefront

Designed an ultra-clean, minimal interactive frontend optimized for asset-heavy clothing imagery. Built multi-device responsive search systems, dynamic product filtering, sizing variables, and fluid canvas animations to elevate customer retention rates.

Robust Inventory & Order Backend

Engineered a highly structural relational schema backend to seamlessly track product variables, item allocations, customer orders, and dispatch logs. Handled security layers to prevent cart anomalies and system vulnerabilities.

Optimized Checkout Pipeline

Focused heavily on cart psychology by pruning the user checkout flow down to core essential interactions. Implemented real-time order summaries, local shipping rules logic, and optimized transaction state processing pipelines.
