The Problem: Buddy Punching

Many universities have transitioned to digital attendance systems (like scanning a static QR code). However, these single-factor verification methods introduced a massive loophole: proxy attendance. A student could simply photograph the QR code and send it to an absent friend to scan from their dorm room.

We needed a system that definitively proved a student's physical presence in the lecture hall, without the high deployment costs or privacy concerns of biometric facial recognition hardware.

The Solution: A Dual-Layer Approach

I engineered SmartTrack, a Mobile-Backend-as-a-Service (MBaaS) application that intercepts fraud by introducing a rigorous multi-layered validation pipeline.

1. Dynamic Time-Variant QR

The QR token refreshes dynamically throughout the session. If a code is shared, it expires before an absent student can scan it.

2. GPS Proximity Geofencing

Utilizing the Haversine formula, the app calculates the distance between the scanning device and the lecturer. It strictly rejects scans over 5 meters away.

3. Network Validation

A secondary check ensures the student is connected to the localized campus Wi-Fi SSID, completely locking out remote network scans.

Faculty & Management Workflows

For lecturers, the goal was reducing administrative burden. The interface needed to be highly actionable, allowing them to start sessions, generate dynamic QR codes, and monitor attendance metrics instantly.

Teacher's Dashboard: Central hub for managing subjects, launching sessions, and accessing visual analytics.
Dynamic QR Generator: Time-scoped (e.g., 5-30 min) tokens mapped with background GPS coordinate binding.
Real-time Analytics: MPAndroidChart integration visualizing attendance ratios instantly across subjects.
Automated Audit Logs: Tracking failed check-in attempts and their exact GPS distances to monitor fraud attempts.

Student Experience & Gamification

The student app was designed to be friction-less for checking in, while providing transparent records and incentivizing good attendance behavior through gamification.

Student Dashboard: A prominent direct-scan action button coupled with dynamic daily schedule integration.
CameraX Integration: Real-time payload decoding and background location capture to execute validation.
Health Indicators: Color-coded progress bars (Green >80%, Yellow 70-79%, Red ≤69%) for immediate feedback.
Gamification Rewards: Students unlock profile avatar frames based on streak milestones (12, 24, 50 continuous classes).

Security Feedback & Edge Cases

A security system is only as good as its error handling. I ensured the UX provided clear, actionable feedback when the validation engine intercepted a fraudulent or invalid scan.

Geofence Interception: Scan explicitly rejected when the user's distance exceeds the 5-meter threshold.
Token Expiry Interception: Attempting to scan a previously photographed QR code prompts an expiration error.

System Performance & Impact

Extensive User Acceptance Testing (UAT) was conducted across 6 trial lecture sessions. The results validated the system's effectiveness:

  • 100% Interception Rate: The geofence and token engine successfully blocked all out-of-bounds proxy attempts.
  • 98.2% Seamless Accuracy: For legitimate scans within the classroom, the system verified attendance on the very first attempt.
  • Behavioral Shift: The introduction of streak calculations and profile frames shifted attendance from a mandatory chore to an engaging habit.
