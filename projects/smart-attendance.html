Not Just Another Attendance System

Many people mistake this project for a basic hotel management system or a simple QR attendance tracker. However, SmartTrack was built differently to solve a critical issue: proxy attendance (buddy punching). Traditional digital systems rely on single-factor verification, meaning a QR code could easily be screenshotted and shared with students not physically present in the classroom.

To combat this, I engineered a rigorous dual-layer verification pipeline. For an attendance record to be accepted, the student's device must prove physical proximity to the lecturer's device (under 5 meters using GPS Haversine formulas) and confirm it is actively connected to the specified campus Wi-Fi network (SSID hashing). This multilayered constraint fundamentally blocks remote check-in fraud.

Key Features & Architecture

Dual-Layer Security Engine

Combines strict GPS proximity geofencing with real-time Wi-Fi SSID network validation, ensuring the user is truly physically present in the lecture hall.

Dynamic Time-Variant QR

Tokens embedded within the generated QR codes are scoped to specific timestamps and refresh repeatedly throughout the session, rendering shared codes useless.

MBaaS Cloud Architecture

Leverages Firebase Authentication and Realtime Database (NoSQL) for instantaneous cross-device synchronization between the Student and Lecturer dashboards.

Gamified User Experience

Incentivizes students with streak calculations, color-coded attendance health metrics, and unlockable profile frames based on milestone achievements.

System Performance

The system was subjected to exhaustive unit, integration, and acceptance testing with faculty and students. The dual-layer validation engine successfully rejected 100% of out-of-range scan attempts while maintaining a 98.2% valid scan acceptance rate on the first attempt, proving that robust security doesn't have to compromise user experience.
